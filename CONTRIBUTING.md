# Contributing to Meshmerize

Contributions to firmware, hardware documentation and diagnostics are welcome.

## Issues

Include firmware variant (`code/`, `just_code/` or `trial_code/`), hardware setup, track material, steps to reproduce, expected behavior and actual behavior. Sensor logs and video are especially useful for line-tracking reports.

## Pull requests

- Keep changes focused and explain the motivation.
- Separate documentation-only changes from control-firmware changes.
- State whether the change compiled and was tested on the physical robot.
- Document pin, calibration, motor polarity and timing changes.
- Avoid unnecessary binary files, credentials and duplicated high-resolution media.
